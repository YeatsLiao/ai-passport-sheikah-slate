## 六、ESP32‑C3 硬性约束清单（开发必看）

1. 图片资源全部存放 SD 卡，禁止内置到 Flash；图片必须压缩小尺寸

2. LVGL 关闭全部不需要的控件、动画、模糊效果；关闭双缓冲，使用单缓冲，节省 RAM

3. 海拉鲁图鉴 json 文件拆分，**只进入对应分类才加载该分类 json，退出立刻释放内存，禁止一次性加载全部数据**

4. 不要同时跑 WiFi \(MQTT\) 和全套希卡石板 UI，内存不足，建议做成菜单选项，二选一启动

5. SPI 屏幕分辨率建议 240×240 以内；分辨率越高内存压力越大

6. 不支持大图解码，图片格式选用 SQOI/SJPG，减少内存占用
